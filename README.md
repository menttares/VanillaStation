# VanillaStation | Space Station 14

VanillaStation — независимый русскоязычный сервер Space Station 14, основанный на сборке Corvax Main.

Проект сохраняет классическую концепцию Space Station 14, используя механики и контент Corvax с возможностью собственных изменений.

## Разработка и сборка

Проект использует движок [Robust Toolbox](https://github.com/space-wizards/RobustToolbox), написанный на C#.

Для локальной сборки:

1. Клонируйте репозиторий проекта.
2. Выполните `python RUN_THIS.py` для инициализации необходимых компонентов.
3. Соберите проект командой `dotnet build`.
